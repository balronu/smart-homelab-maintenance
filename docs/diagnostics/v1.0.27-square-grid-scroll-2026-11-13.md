# Scroll-Diagnose v1.0.27 / 13.11.2026

## Deutsch

Die produktive View `updates-wartung` ist eine Sections-Ansicht. Die
Wartungskarte liegt in einer äußeren Lovelace-`grid`-Karte ohne explizites
`square:false`. Home Assistant aktiviert für diese Karte standardmäßig das
quadratische Layout. Dadurch erhält der Wrapper auf schmalen Viewports eine
feste Seitenverhältnis-Höhe und schneidet die dynamisch wachsende
Containerliste ab. `rows:auto` und der vorhandene `ResizeObserver` der
Custom Card können eine solche übergeordnete Begrenzung nicht aufheben.

Der Fix erkennt ausschließlich einen `hui-grid-card`-Vorfahren mit gesetztem
`square`-Attribut, entfernt das Attribut nur für die Lebensdauer dieser
Wartungskarte und stellt es beim Entfernen der Karte wieder her. Die Karte
bleibt ansonsten bei `columns:full` und `rows:auto`; es werden keine
Scrollpositionen oder Fokuszustände programmgesteuert verändert.

Die Diagnosefunktion `window.smartHomelabMaintenanceScrollDiagnostics()`
weist den Wrapper und den angewendeten natürlichen Höhenmodus aus.

## English

The production `updates-wartung` view is a Sections view. The maintenance
card is nested in an outer Lovelace `grid` card without an explicit
`square:false`. Home Assistant therefore enables the grid card's square
layout by default. On narrow viewports that gives the wrapper a fixed
aspect-ratio height and clips the dynamically growing container list.
`rows:auto` and the existing custom-card `ResizeObserver` cannot remove an
ancestor's fixed constraint.

The fix only detects a `hui-grid-card` ancestor with the `square` attribute,
removes that attribute for the lifetime of this maintenance card, and
restores it when the card is disconnected. No programmatic scrolling or
focus changes are introduced.

The `window.smartHomelabMaintenanceScrollDiagnostics()` probe reports the
wrapper and whether natural height was applied.

## Evidence and limitation

The live Home Assistant dashboard configuration and the served v1.0.27
bundle were read-only verified. The regression fixture reproduces the
square-wrapper failure with twelve containers and verifies that the twelfth
item remains reachable after the fix. An authenticated Home Assistant iOS
WebView and real iPhone touch gesture were not available; production
installation and dashboard mutation were therefore not performed.
