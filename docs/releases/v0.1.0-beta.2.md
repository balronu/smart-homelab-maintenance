# Smart Homelab Maintenance v0.1.0-beta.2

## Deutsch

### Änderungen

- Der Config Flow funktioniert jetzt auch, wenn ausschließlich das
  Home-Assistant-Integrationsverzeichnis installiert ist.
- Der HTTP-Transport ist innerhalb der Integration gebündelt.
- Unzulässige Laufzeitimporte aus dem separaten Agent-Paket wurden entfernt.
- Ein isolierter HA-Runtime-Regressionstest deckt diesen Installationsfall ab.

### Kompatibilität und Installation

Die Beta bleibt passiv und read-only. Die Updateausführung ist deaktiviert.
Die Integration kann ohne das separate Agent-Paket importiert werden. Vor einer
Installation muss der vorhandene Config-Flow-Fehler durch diese Beta behoben
sein; ein Neustart von Home Assistant ist nach einer Paketaktualisierung
weiterhin erforderlich.

### Einschränkungen

Produktive HA- und Proxmox-Systeme wurden nicht mit dieser Beta getestet oder
verändert. Die Agent-Kommunikation bleibt auf die dokumentierten, abgesicherten
Transportgrenzen beschränkt.

## English

### Changes

- The config flow now works when only the Home Assistant integration directory
  is installed.
- The HTTP transport is bundled inside the integration package.
- Invalid runtime imports from the separate agent package were removed.
- An isolated HA runtime regression test covers this installation scenario.

### Compatibility and installation

This beta remains passive and read-only. Update execution is disabled. The
integration can be imported without the separate agent package. After updating
the package, Home Assistant still requires a restart before the config flow is
available.

### Limitations

Productive Home Assistant and Proxmox systems were not tested or changed with
this beta. Agent communication remains limited to the documented secured
transport boundaries.
