# Smart Homelab Maintenance v0.1.0-beta.34

## Deutsch

Diese Beta ergänzt die erste kontrollierte Updateausführung für ausdrücklich
autorisierte laufende Debian-/Ubuntu-LXCs. Simulation und echte Updates haben
getrennte Berechtigungen. Eine Aktualisierung benötigt einen frischen Plan,
den passenden Digest und eine explizite Bestätigung in Home Assistant.

Der Helper führt ausschließlich `apt-get update` und anschließend
`apt-get --yes --no-remove upgrade` aus. Dist-Upgrade, Paketentfernung,
Host-/VM-Ziele und automatische Neustarts sind ausgeschlossen. Der sichere
Default `execution_enabled = false` bleibt aktiv; diese Veröffentlichung führt
keinen produktiven Paketlauf aus.

## English

This beta adds the first controlled update execution path for explicitly
authorized running Debian/Ubuntu LXCs. Simulation and real updates use
separate permissions. An update requires a fresh plan, matching digest, and
explicit confirmation in Home Assistant.

The helper runs only `apt-get update` followed by
`apt-get --yes --no-remove upgrade`. Dist-upgrade, package removal, host/VM
targets, and automatic reboots are excluded. The safe default
`execution_enabled = false` remains active; this release performs no
productive package run.

## Limitations / Einschränkungen

- A real productive update still requires a separately approved target and
  execution window.
- VMs and the Proxmox host remain monitoring-only for this path.
- HA installation and productive guest package changes are not performed by
  CI or by publication of this prerelease.
