# v0.1.0-beta.24 – Kanonischer Dry-Run-Planvergleich (Kandidat)

## Deutsch

Beta.24 behebt einen falschen `update plan changed; dry run is stale`-Abbruch.
Die passive APT-Prüfung und `apt-get --simulate` können denselben Paketplan in
unterschiedlicher Reihenfolge liefern. Beide Quellen werden jetzt vor dem
Vergleich kanonisch sortiert. Echte Änderungen an Paketnamen oder Versionen
bleiben sicherheitsbedingt ein Abbruch.

Die Karte behandelt unbekannte Speicherwerte ausdrücklich als unbekannt statt
als 0 %, übersetzt fehlenden autorisierten Gastzugriff und hält die beiden
Aktionsschaltflächen auf mobilen und größeren Ansichten stabil. **Updates
installieren** bleibt dauerhaft deaktiviert; es gibt keinen serverseitigen
Ausführungspfad.

Der Release-Kandidat ist nicht produktiv installiert. Beta.23 und der separat
installierte Agent bleiben bis zu einer ausdrücklichen Freigabe unverändert.

## English

Beta.24 fixes a false `update plan changed; dry run is stale` rejection. The
passive APT check and `apt-get --simulate` may return the same package plan in
different orders. Both sources are now canonicalized before comparison. Real
package or version changes remain a safety abort.

The card treats unknown memory values as unknown instead of 0%, localizes
missing authorized guest access, and keeps both action buttons stable on mobile
and larger layouts. **Install updates** remains permanently disabled; no server
execution path is provided.

This is a release candidate only. Beta.23 and the separately installed agent
remain unchanged until explicitly approved.
