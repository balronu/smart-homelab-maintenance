# Smart Homelab Maintenance v0.1.0-beta.41

## Deutsch

Beta.41 ist der eindeutige Release-Kandidat für den Policy-Migrationsfix nach
Beta.40. Der Agent bleibt unprivilegiert; eine bestehende `root:root 0600`
Policy wird ausschließlich über den authentifizierten root-eigenen Helper-Socket
gelesen und atomar geändert. Bestehende Simulationsfreigaben bleiben erhalten.

Der Fix ist in PR #66 vollständig CI-geprüft, aber noch nicht gemergt,
veröffentlicht oder produktiv installiert. `execution_enabled=false`, getrennte
Simulations-/Updateberechtigungen und Fail-Closed-Verhalten bleiben bestehen.

Der echte `helper → pct → nichtproduktiver LXC`-Paketlauf ist nicht
nachgewiesen. Beta.41 ist daher kein vollständiger E2E-Abschluss und keine
Stable-Freigabe.

## English

Beta.41 is the uniquely versioned release candidate for the Beta.40 policy
migration fix. The agent remains unprivileged; an existing `root:root 0600`
policy is read and atomically changed only through the authenticated root-owned
helper socket. Existing simulation grants are preserved.

The fix is fully CI-validated in PR #66, but has not been merged, published, or
installed productively. `execution_enabled=false`, separate simulation/update
authorization, and fail-closed behavior remain unchanged.

The real `helper → pct → non-production LXC` package run is not proven.
Beta.41 is therefore not full E2E acceptance and is not Stable.

## Migration note

After separate approval, install the HA integration and agent from the same
verified Beta.41 commit. Run the official preflight, preserve the existing
CT110 simulation grant, verify health/API/helper status, and keep update
authorization disabled. No package action is part of this migration.
