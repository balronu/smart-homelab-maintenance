# v0.1.0-beta.31 – Stable mobile action rows and guest boundaries

## Deutsch

Beta.31 trennt die Simulations-/Installationszeile dauerhaft vom
Simulationsergebnis. Beide Schaltflächen bleiben gleich groß und nebeneinander;
Ergebnis, Paketanzahl, Sicherheitsstatus und eingeklappte Paketdetails stehen
darunter und bleiben auf iPhone, iPad und Desktop stabil.

Die Host-Simulation bleibt read-only. LXC-Simulation bleibt an laufenden
Zustand, unterstützten Paketmanager, explizite Zielautorisierung, feste
Operationen, Timeout und Concurrency-Schutz gebunden; im Release wird kein
produktiver Helper oder keine Allowlist aktiviert.

VMs sind dauerhaft Monitoring-only. VM 104 (HAOS) und VM 106 (PBS) werden mit
Name, Laufstatus und Ressourcen angezeigt, aber nicht auf Pakete geprüft und
nicht simuliert. Keine VM-ID erreicht `pct exec` oder einen anderen
Update-Runner. Echte Paketinstallationen bleiben deaktiviert.

Der Beta.28-APT-Parser für `amd64`/`all`, die kanonische Planprüfung und der
Beta.29-Lifecycle-Schutz für `NRestarts`, `InvocationID` und monotone Startzeit
bleiben enthalten. API-Vertrag 1.1 bleibt unverändert.

## English

Beta.31 permanently separates the simulation/install action row from its
result. Both buttons remain equal-sized and side by side; results, package
counts, safety status, and collapsed package details render below and remain
stable on iPhone, iPad, and desktop.

Host simulation remains read-only. LXC simulation remains bound to a running
target, supported package manager, explicit target authorization, fixed
operations, timeouts, and concurrency protection; this release enables no
production helper or allowlist.

VMs are permanently monitoring-only. VM 104 (HAOS) and VM 106 (PBS) remain
visible with name, runtime state, and resources, but are never package-checked
or simulated. No VM identifier reaches `pct exec` or another update runner.
Real package installation remains disabled.

The Beta.28 APT parser for `amd64`/`all`, canonical plan validation, and the
Beta.29 lifecycle safeguards for `NRestarts`, `InvocationID`, and monotonic
start time remain included. API contract 1.1 is unchanged.

## Compatibility, migration, and limitations

- GitHub prerelease only; no Stable release is created.
- HACS updates the Home Assistant integration only; the external agent is
  versioned separately and requires its official updater.
- No productive agent or Home Assistant installation, restart, dry run,
  package update, firewall change, backup, snapshot, helper, socket, or
  allowlist activation is included.
- VMs are monitoring-only by permanent product decision. LXC simulation needs
  a separately reviewed authorization and helper readiness.
- Before any later production rollout, perform a separately authorized
  read-only preflight and verify TLS, API 1.1, rollback, and the nine CI gates.
