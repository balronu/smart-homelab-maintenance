# v0.1.0-beta.11 – Lovelace-Scrollstabilität (Prerelease)

## Deutsch

### Änderungen

- Bestehende VM-/LXC-Artikel werden bei `hass`-Aktualisierungen nicht mehr
  unnötig aus dem Grid entfernt und erneut eingefügt.
- Regressionen prüfen Scrollposition, DOM-Identität, Grid-Mutationen,
  Fokusverlust, äußeren Lovelace-Kartenbaum, Aufklappzustände und drei
  unabhängige Karteninstanzen.
- Die Browser-Matrix deckt iPhone-, iPad- und Desktop-Viewports ab.

### Kompatibilität und Einschränkungen

- Dies ist eine GitHub-Prerelease für HACS.
- Der abschließende Praxistest in der Home-Assistant-iOS-App bleibt erforderlich;
  Browser- und CI-Tests ersetzen keinen iPhone-Praxistest.
- Keine automatische Installation und kein Home-Assistant-Neustart.

## English

### Changes

- Existing VM/LXC articles are no longer unnecessarily removed and reinserted
  into the grids during ordinary `hass` updates.
- Regression coverage checks scroll position, DOM identity, grid mutations,
  focus retention, the outer Lovelace card tree, disclosure state, and three
  independent card instances.
- The browser matrix covers iPhone, iPad, and desktop viewports.

### Compatibility and limitations

- This is a GitHub prerelease for HACS.
- The final Home Assistant iOS app field test is still required; browser and CI
  tests do not replace an iPhone field test.
- No automatic installation and no Home Assistant restart are performed.
