# Smart Homelab Maintenance v1.0.4 – Stable

## Deutsch

v1.0.4 wartet nach einer Berechtigungsänderung auf die bestätigte Konvergenz
zwischen Home-Assistant-State und Backend-Readback, bevor Erfolg gemeldet wird.
Fehlende, widersprüchliche oder verspätete Readbacks bleiben sichtbar und
werden fail-closed behandelt. Die Berechtigungs-, Update- und
Simulationszustände bleiben pro Container getrennt.

API-Vertrag `1.1`, bestehende Config Entries, Grants und Policies bleiben
erhalten. Der externe Agent 1.0.0 bleibt kompatibel. `execution_enabled=false`
bleibt unverändert; diese Version installiert keine Pakete.

Nach dem HACS-Update die Lovelace-Ressource oder den Browsercache neu laden.
Ein vollständiger Home-Assistant-Neustart ist nicht erforderlich.

## English

v1.0.4 waits for confirmed convergence between Home Assistant state and backend
readback after a permission change before reporting success. Missing,
contradictory, or delayed readback remains visible and is handled fail-closed.
Permission, update, and simulation state remain isolated per container.

API contract `1.1`, existing Config Entries, grants, and policies are
preserved. External Agent 1.0.0 remains compatible. `execution_enabled=false`
is unchanged; this release does not install packages.

After the HACS update, reload the Lovelace resource or browser cache. A full
Home Assistant restart is not required.
