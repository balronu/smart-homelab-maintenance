# Smart Homelab Maintenance v1.0.0-rc.1

## Deutsch

Der Release-Kandidat enthält die kontrollierte LXC-Orchestrierung und den
fail-closed Update-Workflow aus PR #77. Jobs werden persistent gespeichert,
vor einer Paketmutation erneut simuliert und benötigen eine getrennte
Installationsbestätigung. Unsichere Zustände führen zu
`manual_recovery_required`; automatische Wiederholung, Reparatur, Rollback und
Reboot bleiben ausgeschlossen. `execution_enabled=false` bleibt aktiv.

**Kompatibilität und Abnahme:** Die CI deckt Python/API, HA-Runtime und
Runtime-Tests, Browser/Playwright, Frontend-Verträge, HACS, Hassfest, Security
und Installer/systemd ab. Die reale iPhone/iPad-Abnahme, die isolierte
administrative Paket-Abnahme und jede produktive Installation sind noch offen.

## English

This release candidate contains the controlled LXC orchestration and the
fail-closed update workflow from PR #77. Jobs are persisted, simulated again
before package mutation, and require a separate installation confirmation.
Uncertain states become `manual_recovery_required`; automatic retry, repair,
rollback and reboot remain excluded. `execution_enabled=false` stays enabled.

**Compatibility and acceptance:** CI covers Python/API, Home Assistant runtime
and runtime tests, Browser/Playwright, frontend contracts, HACS, Hassfest,
security, and installer/systemd. Real iPhone/iPad acceptance, isolated
administrative package acceptance, and any productive installation remain open.

**Required post-update step:** Select this pre-release explicitly in HACS if it
is to be tested; a Git tag alone does not change a user's HACS pre-release
selection. Do not install it on VM104 or pve-home.
