# v0.1.0-beta.18 – gemeinsamer Updatevertrag (Kandidat)

## Deutsch

- Gemeinsame Beta-Version für Integration, Karte und Agent.
- Healthcheck meldet Agent-Version und API-Vertrag.
- Home Assistant zeigt Versionszustände als aktuell, veraltet, inkompatibel
  oder unbekannt.
- HACS aktualisiert den Agenten nicht automatisch.
- `scripts/upgrade-agent.sh` verlangt Preflight und ausdrückliche Bestätigung,
  prüft die Integrität und führt nach dem Dienstneustart einen Healthcheck aus.
- Fehlgeschlagene Healthchecks lösen eine Wiederherstellung des temporären
  Rollback-Stands aus.
- Keine echten Systemupdates, Paketinstallationen, Snapshots oder
  Proxmox-/VM-/LXC-Änderungen.

Dieser Text beschreibt einen Releasekandidaten. Die Beta ist noch nicht
veröffentlicht und wurde nicht produktiv installiert.

## English

- One coordinated beta version for the integration, card, and agent.
- The health endpoint reports the agent version and API contract.
- Home Assistant shows current, outdated, incompatible, or unknown states.
- HACS never updates the separate agent automatically.
- `scripts/upgrade-agent.sh` requires preflight and explicit confirmation,
  verifies integrity, and performs a health check after the service restart.
- A failed health check restores the temporary rollback state.
- No real system updates, package installations, snapshots, or
  Proxmox/VM/LXC changes.

This document describes a release candidate. Beta.18 is not released and was
not installed in production.
