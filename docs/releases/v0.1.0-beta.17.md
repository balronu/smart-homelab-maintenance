# v0.1.0-beta.17 – Ressourcen- und Agent-Vertrag (Prerelease)

## Deutsch

### Änderungen

- Host-Erreichbarkeit ist von optionalen CPU-, RAM- und Speicherwerten getrennt;
  fehlende Werte bleiben unbekannt statt als null zu erscheinen.
- LXC-Freiwerte bleiben erhalten. VM-Werte werden als Proxmox-Zuweisungen
  dargestellt; Gast-RAM- und Gast-Dateisystem-Freiräume werden nicht erfunden.
- Die Karte zeigt kompakte, beschriftete CPU-, RAM- und Speicherbalken und
  kennzeichnet VM-Datenträger als virtuelle Disk.
- Der Agent-Healthcheck liefert `agent_version`; Integration und Agent müssen
  für den Ressourcenvertrag gemeinsam auf Beta.17 stehen.
- Keine echte Updateausführung; Dry Run und Update-Erkennung bleiben begrenzt.

### Einschränkungen

- HACS aktualisiert nur Integration und Lovelace-Karte. Der Agent wird separat
  aus demselben geprüften Commit vorgeprüft und freigegeben aktualisiert.
- Die Browsermatrix deckt iPhone-Viewports ab, ersetzt aber keinen echten
  Home-Assistant-iOS-Praxistest. Der Scrollfix ist nicht endgültig bestätigt.

## English

### Changes

- Host reachability is separated from optional CPU, RAM, and storage metrics;
  missing values remain unknown instead of becoming fabricated zeroes.
- LXC free-resource values are preserved. VM values represent Proxmox
  allocations; guest RAM and guest filesystem free space are not invented.
- The card provides compact, labelled CPU, RAM, and storage bars and labels VM
  disks as virtual disks.
- The agent health response exposes `agent_version`; the integration and agent
  must both be on Beta.17 for the resource contract.
- Real update execution remains disabled; update detection and dry run remain
  bounded and read-only.

### Limitations

- HACS updates only the integration and Lovelace card. The agent is separately
  preflighted and explicitly approved from the same checked commit.
- The browser matrix covers iPhone viewports but does not replace a real
  Home-Assistant iOS field test. The scroll fix is not finally confirmed.
