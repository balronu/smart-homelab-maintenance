# Smart Homelab Maintenance v0.1.0-beta.5 – Lovelace-Prerelease-Kandidat

## Deutsch

Beta.5 behebt einen Fehler im grafischen Lovelace-Karteneditor auf mobilen
Ansichten. Ein erneutes `setConfig()` während einer laufenden Bearbeitung ersetzt
nicht mehr das gesamte Editor-DOM. Dadurch bleiben Fokus und ungespeicherte
Eingaben auch bei einem zwischenzeitlichen Home-Assistant-Update erhalten.

Die isolierte Playwright-Matrix deckt iPhone, iPad und Desktop sowie Light-/Dark-
Mode, leere und unbekannte Entity-Zustände, Editor-Interaktion, JavaScript-
Fehler, fehlgeschlagene Requests und horizontales Überlaufen ab.

Der Kandidat ist ausschließlich lesend. Es wurden keine produktiven Home-
Assistant-Installationen, Neustarts, Backups, Snapshots oder Agent-Änderungen
durchgeführt.

## English

Beta.5 fixes a mobile Lovelace card-editor defect. A repeated `setConfig()` call
during editing no longer replaces the entire editor DOM, preserving focus and
unsaved input across an intermediate Home Assistant update.

The isolated Playwright matrix covers iPhone, iPad, and desktop viewports in
light and dark mode, empty and unknown entity states, editor interaction,
JavaScript errors, failed requests, and horizontal overflow.

The candidate is read-only. No productive Home Assistant installation,
restart, backup, snapshot, or agent change was performed.
