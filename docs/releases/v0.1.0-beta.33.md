# v0.1.0-beta.33 – Release consistency and safe update boundaries

## Deutsch

Beta.33 synchronisiert die Versionsangaben des Offline-Agenten, der
Home-Assistant-Integration, des Lovelace-Karten-Cache-Schlüssels und des
Manifestes. Eine Regression verhindert künftig, dass ein Teil der
Installation eine ältere Beta meldet.

Die bestehende Sicherheitsgrenze bleibt unverändert: Für ausdrücklich
autorisierte Ziele sind feste, nicht-invasive APT-Simulationen vorgesehen.
Echte Paketinstallationen, Entfernungen und `apt update` bleiben serverseitig
deaktiviert. Die Allowlist wird nicht automatisch erweitert; VMs bleiben
Monitoring-only und gestoppte LXCs werden nicht gestartet.

HACS installiert nur die Home-Assistant-Integration und die Lovelace-Karte.
Der externe Agent bleibt ein separat gepflegter Dienst. Diese Beta ist kein
Stable-Release und wurde nicht in Home Assistant installiert.

## English

Beta.33 synchronizes the version declarations of the offline agent, Home
Assistant integration, Lovelace card cache key, and manifest. A regression
guard prevents one part of an installation from reporting an older beta.

The existing safety boundary is unchanged: fixed, non-invasive APT
simulations are available for explicitly authorized targets. Real package
installation, removal, and `apt update` remain disabled server-side. The
allowlist is never expanded automatically; VMs remain monitoring-only and
stopped LXCs are never started.

HACS installs only the Home Assistant integration and Lovelace card. The
external agent remains a separately maintained service. This is not a Stable
release and it was not installed into Home Assistant.

## Verification and limitations

- Requires the full repository CI matrix and the installer-root-systemd job
  to pass on the exact release commit.
- No productive HA installation, guest probe, simulation, package action,
  VM access, restart, backup, or snapshot is performed by this release work.
