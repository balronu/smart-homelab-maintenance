# Smart Homelab Maintenance v0.1.0-beta.46

## Deutsch

Beta.46 behebt die fehlende sichtbare Rückmeldung bei LXC-Berechtigungsänderungen
in der Lovelace-Karte. Erfolg, HTTP-400/403/500-Fehler, fehlende Berechtigung und
Timeouts werden direkt angezeigt; Ladezustände werden zuverlässig zurückgesetzt.
Erfolgreiche `set_permissions`-Aufrufe lösen einen Coordinator-Refresh aus.
Die Beta.45-Inventory-Recovery bleibt enthalten: 2 VMs und 10 LXCs werden nach
einem fehlgeschlagenen Erstpoll automatisch und duplikatfrei angelegt.
`execution_enabled=false` und die Sicherheitsgrenzen bleiben unverändert.

Beta.46 ist eine GitHub-Prerelease. Es wurden keine produktiven Systeme, Grants,
Policies, Paketaktionen oder Home-Assistant-Instanzen geändert.

## English

Beta.46 fixes missing visible feedback for LXC permission changes in the Lovelace
card. Success, HTTP 400/403/500 errors, missing permission, and timeouts are shown
directly; loading states are reliably reset. Successful `set_permissions` calls
request a coordinator refresh. Beta.45 inventory recovery remains included: 2 VMs
and 10 LXCs are materialized automatically and without duplicates after a failed
first poll. `execution_enabled=false` and the security boundaries remain unchanged.

Beta.46 is a GitHub prerelease. No productive systems, grants, policies, package
actions, or Home Assistant instances were changed.
