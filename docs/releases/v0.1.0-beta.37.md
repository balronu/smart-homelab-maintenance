# Smart Homelab Maintenance v0.1.0-beta.37

## Deutsch

Diese Beta behebt die letzte technische Sperre des read-only LXC-Pfads auf
unprivilegierten Containern: `NoNewPrivileges` verhinderte den von `pct exec`
benötigten Namespace-Aufbau. Die root-eigenen Helper-/Discovery-Units behalten
alle übrigen Einschränkungen, feste Operationen, Timeouts, Peer-UID-Prüfung,
root-eigene Allowlist und VM-Sperre.

`execution_enabled = false` bleibt unverändert; diese Beta führt keine echten
Paketaktionen aus und autorisiert keine zusätzlichen Container.

## English

This beta removes the final technical blocker for the read-only LXC path on
unprivileged containers: `NoNewPrivileges` prevented the namespace setup
required by `pct exec`. The root-owned helper/discovery units retain all other
restrictions, fixed operations, timeouts, peer-UID checks, root-owned allowlist
and VM exclusion.

`execution_enabled = false` remains unchanged; this beta performs no real
package actions and authorizes no additional containers.

## Nach dem Update / Post-update steps

Health, Unit-Sandbox, Socket-Rechte und genau einen autorisierten CT110-Read-/
Simulationslauf prüfen. Echte Updates benötigen weiterhin eine separate
Freigabe.

Verify health, unit sandboxing, socket permissions and exactly one authorized
CT110 read/simulation. Real updates still require separate approval.

## Einschränkungen / Limitations

- VMs und Proxmox-Host bleiben ausgeschlossen.
- Keine automatische Allowlist-Erweiterung.
- Keine echten Paketupdates oder Neustarts.
