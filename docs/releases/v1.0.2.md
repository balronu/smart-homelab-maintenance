# Smart Homelab Maintenance v1.0.2 – Stable

## Deutsch

- Behebt die containerübergreifende Invalidierung der Lovelace-Karte nach einer
  `set_permissions`-Änderung: CT107 behält seinen erfolgreichen
  Simulationssnapshot, wenn CT108 geändert wird.
- Bestätigte Berechtigungs-Readbacks bleiben nach CTID getrennt. Ein globaler
  kurzzeitiger `not_checked`-Readback überschreibt keine fremden
  Containerzustände.
- Fehlender Readback wird als Warnung angezeigt; alte Berechtigungen werden
  nicht dauerhaft als bestätigt dargestellt.

## English

- Fixes cross-container invalidation in the Lovelace card after a
  `set_permissions` change: CT107 retains its successful simulation snapshot
  when CT108 is changed.
- Confirmed permission readbacks remain isolated by CTID. A brief global
  `not_checked` readback cannot overwrite another container's state.
- Missing readback is shown as a warning; old permissions are not presented as
  permanently confirmed.

**Compatibility / migration:** the existing agent 1.0.1 remains compatible and
requires no upgrade. The release's agent version metadata is synchronized to
1.0.2 without behavioral changes. Existing Config Entries and authorization
state are preserved. `execution_enabled=false` remains unchanged.

**Post-update:** reload the Lovelace resource/browser cache. A Home Assistant
restart is not required.

**Known limitation:** live Home Assistant read-only access was unavailable
during diagnosis; no productive grants, package actions, or restarts were
performed.
