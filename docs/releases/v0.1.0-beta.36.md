# Smart Homelab Maintenance v0.1.0-beta.36

## Deutsch

Diese Beta behebt die Proxmox-ACL-Inkompatibilität des LXC-Helpers: Helper und
Discovery behalten root als primäre Gruppe für den benötigten Proxmox-IPC-Zugriff.
Runtime-Verzeichnis und Unix-Sockets werden danach explizit root-owned und nur
für die Agent-Gruppe les-/schreibbar angelegt. Peer-UID-Prüfung und die
root-eigene Allowlist bleiben unverändert.

Der sichere Default bleibt `execution_enabled = false`; Beta.36 erweitert keine
Allowlist und führt selbst keine Paketaktion aus.

## English

This beta fixes the Proxmox ACL incompatibility of the LXC helper: helper and
discovery retain root as their primary group for the required Proxmox IPC access.
The runtime directory and Unix sockets are then explicitly root-owned and
accessible only to the agent group. Peer-UID checks and the root-owned allowlist
are unchanged.

The safe default remains `execution_enabled = false`; Beta.36 does not expand
the allowlist or perform package actions by itself.

## Nach dem Update / Post-update steps

Nach der Installation Helper-/Discovery-Health sowie Runtime- und Socket-Rechte
read-only prüfen; anschließend nur einen ausdrücklich autorisierten LXC
simulieren. Echte Updates erfordern weiterhin eine separate Freigabe.

After installation, verify helper/discovery health and runtime/socket ownership
read-only; then simulate only one explicitly authorized LXC. Real updates still
require separate approval.

## Einschränkungen / Limitations

- Kein produktiver Paket-Update-Lauf enthalten.
- VMs und Proxmox-Host bleiben ausgeschlossen.
- `execution_enabled` bleibt standardmäßig deaktiviert.
