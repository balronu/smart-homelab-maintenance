# v0.1.0-beta.32 – Safe orchestration status and helper readiness

## Deutsch

Beta.32 ergänzt einen read-only Orchestrierungsstatus für den externen Agenten.
Der Status meldet Helper-Installation, Discovery-Socket, Integrität und den
sicheren Policy-Modus `discover_only`, ohne Zugangsdaten oder Gastdaten
auszugeben.

Home Assistant fragt diesen optionalen Endpunkt rückwärtskompatibel ab und
zeigt eine eigene Helper-Status-Entity. Fehlende Helper werden als nicht
verfügbar dargestellt; daraus werden keine Gastberechtigungen abgeleitet.

Die Beta.31-Grenzen bleiben erhalten: VMs sind Monitoring-only, echte
Paketinstallationen, `apt update`, automatische Containerstarts und freie
Shell-Befehle bleiben deaktiviert. Helper und Discovery können separat über
den offiziellen Installer bereitgestellt werden; eine Allowlist wird dabei
nicht automatisch gefüllt. `auto_eligible` ist nicht aktiviert.

HACS installiert nur die Home-Assistant-Integration und Karte. Der externe
Agent bleibt ein separat versionierter Dienst und muss aus demselben geprüften
Commit über seinen offiziellen Updater gepflegt werden. Diese Veröffentlichung
ändert Home Assistant nicht automatisch und ist kein Stable-Release.

## English

Beta.32 adds a read-only orchestration status for the external agent. It
reports helper installation, discovery socket, integrity, and the safe
`discover_only` policy without exposing credentials or guest data.

Home Assistant polls the optional endpoint backward-compatibly and exposes a
dedicated helper-status entity. A missing helper is reported as unavailable;
that state never grants guest permissions.

The Beta.31 boundaries remain: VMs are monitoring-only, real package
installation, `apt update`, automatic container starts, and free shell
commands remain disabled. Helper and discovery can be provisioned separately
through the official installer; no allowlist is populated automatically.
`auto_eligible` is not enabled.

HACS installs only the Home Assistant integration and card. The external agent
remains a separately versioned service and must be maintained from the same
verified commit through its official updater. This release does not alter Home
Assistant automatically and is not a Stable release.

## Verification and limitations

- GitHub prerelease only; no Stable release is created.
- The candidate requires the nine repository gates and the installer-root-systemd
  acceptance job to pass on the exact release commit.
- Productive HA installation, helper activation, allowlist changes, guest
  probes, simulations, package actions, VM access, and CT112 changes remain
  outside this release.
