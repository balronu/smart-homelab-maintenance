# Smart Homelab Maintenance v0.1.0-beta.7 – Lovelace-Sprachfix

## Deutsch

Beta.7 behebt den iPhone-Editorfehler `locale?.toLowerCase is not a function`.
Die Karte und der grafische Editor verwenden jetzt dieselbe typgeprüfte
Sprachauflösung: zuerst `hass.language`, danach ein String oder ein
`hass.locale`-Objekt mit Sprachfeld und anschließend `hass.config.language`.
Fehlende oder unbekannte Angaben fallen auf Englisch zurück.

Die Regressionstests decken deutsche und englische Sprache, objektförmiges
`hass.locale`, fehlende Sprachinformationen, initiales Rendering ohne `hass`,
Vorschau und Editor-Lifecycle ab. Die Karte bleibt ausschließlich lesend.

Installation: Beta.7 als HACS-/GitHub-Prerelease aktualisieren und Home
Assistant entsprechend dem üblichen Frontend-Ressourcen-Reload neu laden.
Es werden keine Proxmox-Aktionen aktiviert.

## English

Beta.7 fixes the iPhone editor error `locale?.toLowerCase is not a function`.
The card and visual editor now share a type-safe language resolver: it prefers
`hass.language`, accepts a string or language field from an object-valued
`hass.locale`, then checks `hass.config.language`, and falls back to English.

Regression coverage includes German and English values, object-valued locale,
missing language information, initial rendering without `hass`, preview, and
the editor lifecycle. The card remains read-only.

Installation: update to the Beta.7 HACS/GitHub prerelease and reload Home
Assistant's frontend resources as normally required. No Proxmox actions are
enabled.
