# v0.1.0-beta.30 – Mobile UI and permanent VM exclusion

## Deutsch

Beta.30 verbessert die mobile Darstellung der read-only Simulationsergebnisse
mit kompakter Paketanzahl, Sicherheitsstatus, eingeklappten Paketdetails und
robustem Touch-/Scrollverhalten auf iPhone, iPad und Desktop. Host-Simulation
bleibt an frische Plan-, TLS- und Sicherheitsprüfungen gebunden; LXC-
Simulationen benötigen laufenden Zustand, nachgewiesenen Debian/Ubuntu-APT-
Support und explizite Zielautorisierung.

VMs sind eine dauerhafte Produktentscheidung: Sie werden vollständig mit Name,
Laufstatus und Ressourcen angezeigt, aber weder auf Pakete geprüft noch
simuliert. Die UI erklärt, dass Updates über das jeweilige Gastbetriebssystem
durchzuführen sind. VM-Kennungen erreichen niemals `pct exec` oder einen
anderen Update-Runner. Echte Paketinstallationen bleiben deaktiviert.

Die Beta.28-APT-Parser-Korrektur für `amd64` und `all`, die kanonische
Planprüfung und der Beta.29-Schutz für `NRestarts`, `InvocationID` und die
monotone Startzeit bleiben enthalten. API-Vertrag 1.1 bleibt unverändert.

## English

Beta.30 improves the mobile rendering of read-only simulation results with a
compact package count, safety status, collapsed package details, and stable
touch/scroll behavior on iPhone, iPad, and desktop. Host simulation remains
bound to fresh plan, TLS, and safety checks; LXC simulation requires a running
target, proven Debian/Ubuntu APT support, and explicit per-target authorization.

VMs are a permanent product decision: they remain fully visible with name,
runtime state, and resources, but are never checked for packages or simulated.
The UI explains that updates must be performed through the respective guest
operating system. VM identifiers never reach `pct exec` or another update
runner. Real package installation remains disabled.

The Beta.28 APT parser fix for `amd64` and `all`, canonical plan validation,
and the Beta.29 safeguards for `NRestarts`, `InvocationID`, and monotonic start
time remain included. API contract 1.1 is unchanged.

## Compatibility and limitations

- GitHub prerelease; stable remains unchanged.
- HACS updates the Home Assistant integration only; the external agent is
  versioned separately.
- No productive agent or Home Assistant installation, restart, dry run,
  package update, firewall change, backup, snapshot, helper, socket, or
  allowlist activation is included.
- VMs are monitoring-only; LXC simulation requires separate reviewed
  authorization and helper readiness.
