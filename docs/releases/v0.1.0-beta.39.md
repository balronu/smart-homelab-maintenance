# Smart Homelab Maintenance v0.1.0-beta.39

## Deutsch

Beta.39 schließt die konkrete Lücke zwischen Update-Anzeige und sicherer
Berechtigungsverwaltung. Simulation und echte Updates sind getrennt pro
laufendem Debian-/Ubuntu-LXC autorisierbar. Die Änderung wird atomar und
root-eigen in Modus `0600` gespeichert; unsichere Konfigurationen bleiben
gesperrt. Ein frischer Dry-Run ist auch bei null verfügbaren Updates möglich.

Die CI führt zusätzlich eine echte Installation und ein Upgrade eines kleinen
Pakets in einem ephemeren dpkg-Root aus. Das ist kein produktiver Gastlauf.

Nach dem Update: Berechtigungen gezielt prüfen, einen frischen Read-/Dry-Run
ausführen und erst danach einen einzelnen bestätigten Updateplan verwenden.
Keine Dist-Upgrades, Paketentfernungen, VM-/Host-Aktionen oder automatischen
Neustarts.

## English

Beta.39 closes the gap between update presentation and safe authorization.
Simulation and real updates can be authorized separately per running
Debian/Ubuntu LXC. The policy is written atomically as root-owned mode `0600`;
unsafe configuration remains blocked. A fresh dry run is also available when
zero updates are present.

CI additionally performs a real installation and upgrade of a small package
inside an ephemeral dpkg root. This is not a productive guest run.

After updating: verify the targeted permissions, perform a fresh read/dry run,
and only then use one explicitly confirmed update plan. No dist-upgrades,
package removals, VM/host actions, or automatic reboots.
