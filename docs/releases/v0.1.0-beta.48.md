# Smart Homelab Maintenance v0.1.0-beta.48

## Deutsch

Beta.48-Kandidat für die Korrektur des Orchestrierungsstatus. Der Agent liest
die geschützte Allowlist weiterhin ausschließlich über den authentifizierten
Helper-Socket und stellt bestehende Legacy- sowie getrennte
Simulationsfreigaben korrekt für Home Assistant dar. Update-Freigaben werden
nicht daraus abgeleitet.

Beschädigte Policy-Antworten und unbekannte Policy-Modi bleiben fail-closed.
Ein GET des Orchestrierungsstatus führt weder Gastprüfungen noch
Allowlist-Schreibvorgänge aus. `last_reconcile_at` wird nicht erfunden, sondern
bleibt bis zu einem nachweislich ausgeführten Reconciliation-Lauf leer.

Der Kandidat ändert weder produktive Home-Assistant-Systeme noch Agent-Dienste.
Es gibt keine automatische Aktivierung von `auto_eligible`, keine Paketaktionen
und kein Release ohne separate Freigabe.

## English

Beta.48 candidate for the orchestration-status mapping fix. The agent continues
to read the protected allowlist only through the authenticated helper socket and
correctly exposes existing legacy and split simulation grants to Home Assistant.
Update authorization is never inferred from a simulation grant.

Malformed policy responses and unknown policy modes fail closed. A GET of the
orchestration status performs no guest probes and writes no grants.
`last_reconcile_at` is never fabricated and remains empty until a proven
reconciliation run sets it.

The candidate changes neither productive Home Assistant systems nor agent
services. It does not enable `auto_eligible`, perform package actions, or create
a release without separate approval.
