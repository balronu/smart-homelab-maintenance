# Smart Homelab Maintenance v0.1.0-beta.40

## Deutsch

Beta.40 ist der eindeutig versionierte Release-Kandidat für PR #65 und die
kontrollierte Migration von HA Beta.39/Agent Beta.37. Agent, Integration und
Karte tragen dieselbe Releaseversion; der API-Vertrag bleibt 1.1.

Der Kandidat enthält die per-LXC-Berechtigungsverwaltung in Home Assistant:
Simulation und echte Updates bleiben getrennt, Berechtigungen werden nur für
geeignete laufende Debian-/Ubuntu-APT-LXCs angeboten, und Änderungen erfordern
einen authentifizierten HA-Administrator sowie die root-eigene Agent-Policy.

Der sichere Default `execution_enabled=false` bleibt unverändert. Es wurden
keine produktiven Berechtigungen, Paketdaten, Automationen oder Dienste
geändert. Der echte `helper → pct → nichtproduktiver LXC`-Paketlauf ist nicht
nachgewiesen; Beta.40 ist deshalb kein vollständiger E2E-Abschluss und keine
Stable-Freigabe.

## English

Beta.40 is the uniquely versioned release candidate for PR #65 and the
controlled migration from HA Beta.39/Agent Beta.37. Agent, integration and
card carry the same release version; API contract 1.1 remains unchanged.

The candidate includes per-LXC permission management in Home Assistant:
simulation and real updates remain separate, permission controls are shown only
for suitable running Debian/Ubuntu APT LXCs, and changes require an
authenticated HA administrator plus the root-owned agent policy.

The safe default `execution_enabled=false` remains unchanged. No productive
permissions, package databases, automations or services were changed. The real
`helper → pct → non-production LXC` package run is not proven; Beta.40 is
therefore not full E2E acceptance and is not Stable.

## Migration note

Install the HA integration and agent only as the same reviewed Beta.40 commit.
Run the documented preflight, preserve the existing CT110 simulation grant,
verify health/API/helper status, and keep update authorization disabled. A
separate approval is required before installation in VM104; no tag or GitHub
release is created by this candidate preparation.
