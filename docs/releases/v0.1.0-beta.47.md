# Smart Homelab Maintenance v0.1.0-beta.47

## Deutsch

Beta.47 behebt den systematischen Eligibility-Fehler nach einer gespeicherten
LXC-Freigabe. Nachgewiesene Debian-/Ubuntu- und APT-Metadaten werden in den
Update-Zieltyp übernommen, sodass geeignete Container nach dem Coordinator-
Refresh nicht mehr fälschlich als „Nicht unterstützt“ erscheinen.

Die Lovelace-Karte validiert Serviceantworten auch bei HTTP 200 mit eingebettetem
Fehler und zeigt keinen irreführenden Erfolg mehr an. Die Trennung zwischen
gespeicherter Autorisierung und tatsächlicher Eligibility bleibt erhalten;
`discover_only` führt weiterhin keine Gastprobe und keine automatische Freigabe
aus. Beta.45-Inventar-Recovery und Beta.46-Berechtigungsfeedback sind enthalten.

Beta.47 ist eine GitHub-Prerelease. Es wurden keine produktiven Systeme,
Container, Grants, Policies, Paketaktionen oder Home-Assistant-Instanzen
geändert. Installation in VM104 erfordert eine separate Freigabe.

## English

Beta.47 fixes the systematic eligibility error after a stored LXC grant. Proven
Debian/Ubuntu and APT metadata is carried into the update target, so eligible
containers are no longer incorrectly shown as unsupported after a coordinator
refresh.

The Lovelace card validates service responses even when HTTP 200 contains an
embedded error and no longer reports misleading success. The separation between
stored authorization and actual eligibility remains; `discover_only` performs no
guest probe and no automatic grant. Beta.45 inventory recovery and Beta.46
permission feedback are included.

Beta.47 is a GitHub prerelease. No productive systems, containers, grants,
policies, package actions, or Home Assistant instances were changed. Installation
in VM104 requires separate approval.
