# Smart Homelab Maintenance v0.1.0-beta.35

## Deutsch

Diese Beta behebt zwei produktionsrelevante LXC-Helper-Sicherheitsfehler:
Die `SO_PEERCRED`-Struktur wird jetzt korrekt als PID, UID, GID gelesen, und
die systemd-Discovery-Unit verwendet dieselbe Runtime-Gruppe wie der Helper.
Damit kann der ausdrücklich konfigurierte Agent den root-eigenen Helper-Socket
erreichen, ohne die Allowlist oder den Berechtigungsumfang zu erweitern.

Der sichere Default bleibt unverändert: `execution_enabled = false`, keine
automatische Allowlist-Erweiterung, keine VM-/Host-Gastzugriffe und keine
Paketaktionen durch die Veröffentlichung selbst.

## English

This beta fixes two production-relevant LXC helper security defects: the
`SO_PEERCRED` structure is now read correctly as PID, UID, GID, and the systemd
discovery unit uses the same runtime group as the helper. The explicitly
configured agent can therefore reach the root-owned helper socket without
expanding the allowlist or privilege scope.

The safe default is unchanged: `execution_enabled = false`, no automatic
allowlist expansion, no VM/host guest access, and no package actions caused by
publishing this release.

## Nach dem Update / Post-update steps

Nach Installation der Beta: Helper-/Discovery-Health, Socket-Besitz und
Gruppenrechte read-only prüfen; anschließend nur ein ausdrücklich autorisiertes
LXC simulieren. Echte Updates benötigen weiterhin eine separate Freigabe.

After installing the beta: verify helper/discovery health, socket ownership and
group permissions read-only; then simulate only one explicitly authorized LXC.
Real updates still require separate approval.

## Einschränkungen / Limitations

- Beta.35 enthält keinen produktiven Paketlauf.
- VMs und der Proxmox-Host bleiben ausgeschlossen.
- `execution_enabled` bleibt standardmäßig deaktiviert.
