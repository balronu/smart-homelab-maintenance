# Smart Homelab Maintenance v1.0.5 – Stable

## Deutsch

v1.0.5 behebt den nachgewiesenen Installations-Timeout: Nach erfolgreicher
Sicherheits- und Digest-Prüfung wird der bestehende persistente Updatejob
serverseitig gestartet und die Job-ID sofort zurückgegeben. Status und Ergebnis
werden über die bereits vorhandenen Job-Endpunkte gelesen. Aktive Jobs sperren
Duplikate pro Container; ein unklarer Ausführungsstatus führt weiterhin zu
Manual-Recovery ohne automatische Wiederholung.

## English

v1.0.5 fixes the proven installation timeout. After the existing security and
digest checks pass, the persistent update job starts server-side and its job ID
is returned immediately. Status and results are read through the existing job
endpoints. Active jobs prevent duplicate execution per container; uncertain
execution remains in manual recovery with no automatic retry.

## Compatibility, migration, and limitations

- API contract `1.1` and Agent 1.0.0 compatibility are preserved.
- Existing Config Entries, grants, and global policy are preserved.
- No package installation is performed by the release itself.
- The prior CT107 job must be manually reconciled before any new execution.
- Reload the Lovelace resource or browser cache after installation; a full HA
  restart is not required.
