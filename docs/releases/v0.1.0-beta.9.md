# Smart Homelab Maintenance v0.1.0-beta.9

## Deutsch

Beta.9 stabilisiert die read-only Lovelace-Karte auf mobilen Home-Assistant-
Ansichten. Der geöffnete Proxmox-Hostbereich bleibt bei wiederholten
Statusupdates geöffnet. Das Raster richtet sich nach der tatsächlichen
Kartenbreite, lange Namen werden umgebrochen und unbekannte OS-Werte nicht mehr
als `unknown unknown` dargestellt. Die doppelte Read-only-Anzeige wurde
entfernt.

Die Karte bleibt ausschließlich lesend. Es gibt keine VM-/LXC-Steuerung,
keine Updatefunktion und keine automatische HA-Installation. Nach dem HACS-
Update installiert der Benutzer die Beta selbst; ein Neustart ist nicht Teil
dieses Releases.

## English

Beta.9 stabilizes the read-only Lovelace card on mobile Home Assistant views.
The expanded Proxmox host section survives repeated state updates. The grid is
based on the actual card width, long names wrap safely, and unknown OS values
are no longer rendered as `unknown unknown`. The duplicate read-only display
was removed.

The card remains read-only. No VM/LXC controls, update actions, or automatic HA
installation are included. The user installs the beta through HACS; a restart
is not performed by this release workflow.
