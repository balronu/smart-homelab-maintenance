# Smart Homelab Maintenance v0.1.0-beta.42 candidate

## Deutsch

Beta.42 bündelt den gezielten Fix für die erste Simulationsfreigabe eines
noch nicht autorisierten LXC. Der Agent prüft vor dem Grant ausschließlich
read-only über den authentifizierten root-Helper, ob der numerische Container
läuft, Debian/Ubuntu meldet und die festen APT-Binaries besitzt. Es werden
keine Paketdatenbanken aktualisiert und keine Pakete verändert.

Widerruf benötigt keine erneute Eignungsprüfung. Unbekannte, gestoppte,
unterstützte oder widersprüchliche Ziele bleiben fail-closed. Die bestehende
Policy bleibt root-owned mit Modus `0600`; `execution_enabled=false` und
CT110s bestehende Simulationsfreigabe bleiben unverändert.

Der echte `helper → pct → nichtproduktiver LXC`-Paketlauf ist weiterhin nicht
nachgewiesen. Diese Beta ist kein Stable-Release und nicht die vollständige
Issue-#63-Abnahme.

## English

Beta.42 bundles the targeted fix for granting simulation to an LXC that has no
existing authorization. Before granting, the agent uses the authenticated
root helper for a strictly read-only proof that the numeric container is
running, reports Debian/Ubuntu, and contains the fixed APT binaries. No package
index is refreshed and no package is changed.

Revocation does not require a fresh eligibility probe. Unknown, stopped,
unsupported, or contradictory targets remain fail-closed. The policy remains
root-owned with mode `0600`; `execution_enabled=false` and CT110's existing
simulation grant are unchanged.

The real `helper → pct → non-production LXC` package run remains unproven.
This beta is not Stable and does not close Issue #63.

## Migration / Migration

After separate approval, install the HA integration, agent, and helper from
the same verified Beta.42 commit. Run the official preflight, restart only the
required helper/agent services, and verify policy, health, and the non-writing
simulation path. Do not grant update authorization or run productive package
updates as part of migration.
