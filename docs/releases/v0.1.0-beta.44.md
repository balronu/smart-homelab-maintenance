# Smart Homelab Maintenance v0.1.0-beta.44 candidate

## Deutsch

Beta.44 ist ein gezielter Hotfix für den nachgewiesenen Beta.43-Fehler unter
der produktiv erforderlichen Policy-Sandbox.

- Der Agent öffnet, prüft oder parst die root-owned Allowlist nicht mehr direkt.
- `policy_read` und `policy_set` verwenden ausschließlich den authentifizierten
  root-owned Helper-Socket.
- Der Orchestrierungsstatus validiert die Policy-Verfügbarkeit pro Anfrage über
  denselben Helper und bleibt bei dessen Ausfall fail-closed.
- `ProtectSystem=strict`, `ReadWritePaths=/etc/smart-homelab-maintenance`,
  Verzeichnis `0700`, Datei `root:root 0600` und
  `execution_enabled=false` bleiben bestehen.

Beta.44 ist nur ein Releasekandidat. Es wurden keine produktiven Systeme,
Grants, Policies, Paketaktionen oder Home-Assistant-Instanzen geändert.
Ein echter Paketlauf in einem nichtproduktiven Proxmox-LXC bleibt eine offene
Abnahmegrenze.

## English

Beta.44 is a narrowly scoped hotfix for the proven Beta.43 failure under the
production-required policy sandbox.

- The agent no longer opens, stats, or parses the root-owned allowlist directly.
- `policy_read` and `policy_set` use only the authenticated root-owned helper
  socket.
- Orchestration status validates policy availability per request through the
  same helper and remains fail-closed when it is unavailable.
- `ProtectSystem=strict`, `ReadWritePaths=/etc/smart-homelab-maintenance`,
  directory mode `0700`, file mode `root:root 0600`, and
  `execution_enabled=false` remain unchanged.

Beta.44 is a release candidate only. No productive systems, grants, policies,
package actions, or Home Assistant instances were changed. A real package run
in a designated non-production Proxmox LXC remains an open acceptance gap.
