# v0.1.0-beta.27 – Restart-race detection and safe rollback

## Deutsch

Beta.27 behebt die Readiness-Lücke, die im kontrollierten Beta.22→Beta.26-
Upgrade sichtbar wurde. Beta.22 lauschte ohne `SO_REUSEADDR`; ein
serverseitiger `TIME-WAIT`-Zustand konnte den neuen Beta.26-Bind trotz dessen
`SO_REUSEADDR` blockieren. Die isolierte Linux-Reproduktion bestätigt diese
Semantik.

Der Updater erfasst deshalb den systemd-Restartzähler vor dem Austausch und
prüft ihn nochmals unmittelbar nach dem erfolgreichen TLS-/API-Healthcheck.
Jeder Anstieg während des Upgradefensters gilt als fehlgeschlagener Start und
führt zum bestehenden kontrollierten Rollback. `SO_REUSEPORT` bleibt
deaktiviert; aktive Listener, Cgroup- und TCP-Sicherheitsprüfungen bleiben
erhalten.

Integration und Agent verwenden `0.1.0-beta.27`; der API-Vertrag bleibt `1.1`.
Der Beta.24-Planvergleich, der Beta.25-Lifecycle-Fix und die Beta.26-
Portdiagnose bleiben enthalten. Der Installationsbutton bleibt dauerhaft
deaktiviert. HACS aktualisiert den externen Agenten nicht automatisch.

## English

Beta.27 closes the readiness gap observed during the controlled
Beta.22-to-Beta.26 upgrade. Beta.22 listened without `SO_REUSEADDR`; a
server-side `TIME-WAIT` state could block the new Beta.26 bind despite its
`SO_REUSEADDR`. The isolated Linux reproduction confirms this behavior.

The updater therefore records the systemd restart counter before the swap and
checks it again immediately after a successful TLS/API healthcheck. Any
increase during the upgrade window is treated as a failed start and activates
the existing controlled rollback. `SO_REUSEPORT` remains disabled; active
listener, cgroup, and TCP safety checks remain in place.

Integration and agent use `0.1.0-beta.27`; the API contract remains `1.1`.
The Beta.24 plan comparison, Beta.25 lifecycle fix, and Beta.26 port
diagnostics remain included. The install button stays permanently disabled.
HACS does not automatically update the external agent.

## Compatibility and limitations

- GitHub prerelease; stable remains unchanged.
- No productive agent or Home Assistant installation, restart, dry run,
  package update, firewall change, backup, snapshot, helper, socket, or
  allowlist activation is included.
- A later productive agent upgrade requires separate explicit authorization,
  preflight, TLS/API readiness, and rollback verification.
