# Smart Homelab Maintenance v0.1.0-beta.4 – Lovelace-Prerelease

> GitHub-Prerelease veröffentlicht. Keine produktive Home-Assistant-
> Installation wurde durchgeführt.

## Deutsch

### Änderungen

- Read-only-Lovelace-Karte für Verbindungsstatus, Proxmox-Host, VMs, LXC-
  Container und Wartungshinweise ergänzt.
- Die Karte erkennt die vorhandenen Host-, VM- und LXC-Entitäten automatisch
  und zeigt nur tatsächlich gelieferte Messwerte.
- Responsive Light-/Dark-Mode-Darstellung, Fortschrittsbalken sowie deutsche
  und englische Beschriftungen ergänzt.
- Die Integration registriert die versionierte Frontend-Ressource automatisch;
  der Karteneditor stellt die Karte ohne manuelle YAML-Ressource bereit.
- Der Coordinator aktualisiert die read-only Daten im konfigurierten Intervall.

### Kompatibilität und Installation

Das Prerelease aktualisiert nur die Integration und ihre Frontend-Ressource.
Bestehende Entitäten und Konfigurationen bleiben erhalten. Nach einer später
freigegebenen Installation ist ein Home-Assistant-Neustart erforderlich, damit
Manifest, Python-Code und Frontend-Ressource sicher neu geladen werden.

### Einschränkungen

Die HA-Runtime- und Browsermatrix konnten in der aktuellen Arbeitsumgebung
nicht ausgeführt werden: Home Assistant, pytest und Playwright sind dort nicht
installiert. Es wurden keine produktiven Systeme verändert.

## English

### Changes

- Added a read-only Lovelace card for connection status, the Proxmox host, VMs,
  LXC containers, and maintenance information.
- The card discovers existing host, VM, and LXC entities and renders only
  values actually supplied by Home Assistant.
- Added responsive light/dark rendering, progress bars, and German/English
  labels.
- The integration registers the versioned frontend resource automatically; the
  card editor exposes the card without a manual YAML resource.
- The coordinator refreshes read-only data at the configured interval.

### Compatibility and installation

The prerelease changes only the integration and its frontend resource. Existing
entities and configuration are preserved. If later approved for installation,
Home Assistant should be restarted so the manifest, Python code, and frontend
resource are reloaded consistently.

### Limitations

The HA runtime and browser matrix could not run in the current workspace because
Home Assistant, pytest, and Playwright are not installed. No productive systems
were changed.
