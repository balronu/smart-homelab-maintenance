# Smart Homelab Maintenance v0.1.0-beta.38

## Deutsch

Diese Beta korrigiert die Kompatibilitätsanzeige der Home-Assistant-Integration:
Beta-Agenten derselben 0.1.0-Release-Linie mit API-Vertrag 1.1 werden als
kompatibel erkannt. Abweichende API-Verträge und unbekannte Versionen bleiben
gesperrt.

Die Änderung erweitert keine Allowlist und aktiviert keine Paketaktionen.

## English

This beta fixes the Home Assistant compatibility display: beta agents from the
same 0.1.0 release line using API contract 1.1 are recognized as compatible.
Mismatched or unknown versions remain blocked.

This change does not expand the allowlist or enable package actions.

## Nach dem Update / Post-update steps

Health and API contract 1.1 should be checked. CT110 remains the only
authorized simulation target; real updates still require separate approval.

## Einschränkungen / Limitations

- VMs and the Proxmox host remain excluded.
- No automatic container authorization is introduced.
- No real package update or removal is performed.
