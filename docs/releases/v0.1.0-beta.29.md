# v0.1.0-beta.29 – Safe systemd lifecycle validation

## Deutsch

Beta.29 erweitert die Beta.28-Restart-Erkennung um die systemd-
`InvocationID` und `ExecMainStartTimestampMonotonic`. Der kontrollierte
Wechsel von der alten zur neuen Unit-Instanz wird ausdrücklich erkannt und
zugelassen. Fehlende oder ungültige `NRestarts`-Werte, Anstiege, unerwartete
Rückgänge/Resets sowie ein späterer Wechsel von InvocationID oder Startzeitpunkt
führen sicher zum bestehenden Rollback.

Die Readiness verlangt weiterhin TLS, Status `ok`, exakt Agent Beta.29 und API
1.1. Der Beta.28-APT-Parser-Fix für `amd64` und `all`, die kanonische
Planprüfung und die Sicherheitsgrenzen bleiben enthalten. Der Installations-
button bleibt dauerhaft deaktiviert.

## English

Beta.29 extends the Beta.28 restart detection with the systemd
`InvocationID` and `ExecMainStartTimestampMonotonic`. The controlled
transition from the old to the new unit instance is explicitly identified and
allowed. Missing or invalid `NRestarts` values, increases, unexpected
decreases/resets, and later changes to the invocation or start timestamp fail
closed into the existing rollback.

Readiness still requires TLS, status `ok`, exactly agent Beta.29, and API 1.1.
The Beta.28 APT parser fix for `amd64` and `all`, canonical plan validation,
and the safety boundaries remain included. The install button stays
permanently disabled.

## Compatibility and limitations

- GitHub prerelease; stable remains unchanged.
- HACS updates the Home Assistant integration only; the external agent is
  versioned separately.
- No productive agent or Home Assistant installation, restart, dry run,
  package update, firewall change, backup, snapshot, helper, socket, or
  allowlist activation is included.
- A later productive upgrade requires separate authorization and a successful
  official preflight.
