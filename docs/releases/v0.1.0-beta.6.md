# Smart Homelab Maintenance v0.1.0-beta.6 – Lovelace-Prerelease-Kandidat

## Deutsch

Beta.6 behebt die mobile Lovelace-Editor-Darstellung. Die Felder werden als
responsive, einspaltiges Layout mit ausreichenden Abständen und lokalisierter
Beschriftung gerendert. Die Kartenklasse meldet ihre Vorschaugröße und rendert
auch ohne sofort verfügbares `hass` einen sichtbaren Offline-/Leerzustand, statt
eine leere Vorschaufläche zu hinterlassen.

Der Playwright-Test umfasst iPhone Hochformat, iPad, Desktop, Light-/Dark-Mode,
Kartenanlage, Entity-Vorschau, Optionsänderung, Speichern und erneutes Öffnen.
Zusätzlich prüft ein HA-Editor-Vertragsharness Picker-Registrierung, Vorschau und
Lebenszyklus.

Der Kandidat ist ausschließlich lesend. Keine produktive HA-Installation,
Neustarts, Backups, Snapshots oder Proxmox-Agent-Änderungen wurden durchgeführt.

## English

Beta.6 fixes the mobile Lovelace editor presentation. Fields use a responsive
single-column layout with adequate spacing and localized labels. The card now
reports its preview size and renders an explicit offline/empty state before
`hass` is available instead of leaving an empty preview area.

Playwright covers iPhone portrait, iPad, desktop, light/dark mode, card creation,
entity preview, option changes, save, and reopen. An HA editor contract harness
also checks picker registration, preview, and lifecycle behavior.

The candidate is read-only. No productive HA installation, restart, backup,
snapshot, or Proxmox-agent change was performed.
